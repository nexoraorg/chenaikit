# scripts

Repo-level scripts (release, codegen, contract build wrappers) that don't
belong to a single app or package.
## Verifying release artifact checksums

Every published release artifact ships with a `SHA256SUMS.txt` alongside
it, generated by `scripts/generate-checksums.sh`.

### Verify a downloaded artifact

No project-specific tooling is required — these are standard SHA-256
checksums, verifiable with tools already on most systems.

**Linux:**
```bash
sha256sum -c SHA256SUMS.txt
```

**macOS:**
```bash
shasum -a 256 -c SHA256SUMS.txt
```

**Windows (PowerShell):**
```powershell
Get-FileHash <file> -Algorithm SHA256
# then compare the Hash value to the matching line in SHA256SUMS.txt
```

A line reading `OK` next to your file means it matches exactly. Any other
result means the file differs from what was published and should not be
trusted.

### Regenerating checksums locally

```bash
scripts/generate-checksums.sh <artifact-dir> [output-file]
# e.g.
scripts/generate-checksums.sh apps/frontend/dist
```

This hashes every file in `<artifact-dir>` (sorted, so the output is
reproducible for identical artifact content) and writes a
`sha256sum`-format `SHA256SUMS.txt`.
